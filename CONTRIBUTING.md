# Contributing

Thank you for considering contributing to the KPI Plugin.

## How to Contribute

1. Fork the repository.
2. Create a new branch.

```bash
git checkout -b feature/my-feature
```

3. Commit your changes.

```bash
git commit -m "Add my feature"
```

4. Push your branch.

```bash
git push origin feature/my-feature
```

5. Open a Pull Request.

## Coding Standards

* Follow PSR-12 coding standards.
* Keep code modular and documented.
* Write descriptive commit messages.
* Test changes before submitting.

## Reporting Bugs

Please include:

* Kanboard version
* PHP version
* Database type
* Steps to reproduce
* Expected behavior
* Actual behavior

## Feature Requests

Describe:

* Problem
* Proposed solution
* Expected benefits
